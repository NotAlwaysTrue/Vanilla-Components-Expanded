# 夜视仪实施记录

新增共享物品组件 `NightVision`。装备与卸下沿用原版物品流程，画面只跟随本机控制的角色。默认戴上即开启；`ToggleKey` 可指定本机开关键，`RequiresPower` 可要求同物品的 `Powered` 组件有电。装备损坏、掉落、失去供电或切换角色后，画面按 `FadeTime` 淡出。联机环境光开关沿用原版设置同步。

客户端采用 MonoGame 3.7.1 编译的 MGFX v8，两份资源分别嵌入 Windows 客户端（DirectX）及 Linux/macOS 客户端（OpenGL）。着色器源码位于 `CsProjectSource/Shaders/NightVision.fx`。重编时用 2MGFX 对同一源文件分别指定 `/Profile:DirectX_11` 和 `/Profile:OpenGL`。自定义效果加载失败时记录错误并使用原版单色效果；回退模式保留淡变、环境光和普通轮廓。

原版 1.15.33 的 `DrawMap` 在基本拷贝与最终后处理两条路径中都会读取 `renderTargetFinal`。插件拦截这两处读取，开启时把处理后的图像写进原版已用完的全尺寸中间纹理。随后仍由原版完成模糊、畸变、气泡、黑幕和 HUD。客户端用临时环境光下限改善暗部，灯光贴图绘制结束即还原。服务端可关闭“允许夜视仪提高环境光”；每件装备也可将 `AmbientBoost` 设为零。

磷光色、增益、黑位、伽马、噪点、扫描线、暗角和镜头畸变均可在物品 XML 调节。`Bloom` 在同一遍绘制中取四个相邻亮部样本。`WhiteHot` 将磷光色改为白色，明暗取自场景亮度。可选热融合依据角色与肢体的原版显示条件绘制，不依赖温度数据。

`ThermalMode` 默认 `Off`。`FusedOutline` 直接绘制肢体轮廓，`Mask` 将轮廓绘入宽高各为四分之一的遮罩，`Edge` 对填充肢体组成的遮罩取边缘。默认每秒刷新六次目标与肢体位置，取视口附近、范围内最近的 16 个角色，上限 32。两次刷新之间，缓存随相机移动。可选测试包包含 `vcenightvisiontest` 护目镜和支持切换信号的 `vcenightvisionlamp` 舱灯。

待测项目：

- 修复后的 DirectX 着色器按 SpriteBatch 的顶点输出顺序读取纹理坐标。待测绿色与白热模式下的世界细节、移动镜头及开关时的闪烁。
- 人类所有可见且未断离的肢体都可显示热轮廓。待测头部、左右脚在走动和转身时的轮廓，以及其他生物的小肢体质量筛选。
- 单人、主机与远端客户端的穿脱、掉落、换人、死亡、断电及回合切换。
- Windows、Linux 与 macOS 上对应着色器的实际加载与显示，原版单色回退，窗口缩放和全屏切换。
- 开关键、淡变、全暗与强光、服务端禁用提亮、白热与泛光。
- 舱内外与移动潜艇上的热轮廓对齐、隐身及死亡过滤、目标上限、原版视线、受伤后处理、气泡、黑幕及 HUD。
- 1080p 下关闭、普通夜视和三种热融合档位的帧耗时，以及与其他后处理模组叠加的画面。

仅完成编译。实际画面、游戏内行为与性能指标待验证。
