# 夜视仪实施记录

新增共享物品组件 `NightVision`。装备与卸下沿用原版物品流程，画面只跟随本机控制的角色。默认戴上即开启；`ToggleKey` 可指定本机开关键，`RequiresPower` 可要求同物品的 `Powered` 组件有电。装备损坏、掉落、失去供电或切换角色后，画面按 `FadeTime` 淡出。联机环境光开关沿用原版设置同步。

## 物品配置

将组件加在可装备的物品上。下例用于头部护目镜，N 键切换，淡变时间为 0.4 秒。组件默认淡变时间为 0.2 秒，默认不绑定切换键。输入文字时不会触发开关。

```xml
<NightVision ToggleKey="N" FadeTime="0.4" AmbientBoost="0.25" />
```

| 参数 | 对画面的影响 |
| --- | --- |
| `AmbientBoost` | 灯光贴图的最低亮度，默认 0.25。设为 0 仍会放大原有光照，例如原版绘制在玩家身边的微弱光晕。 |
| `Gain`、`Lift`、`Gamma` | 调节已经过光照处理的场景亮度，默认依次为 2.5、0.04 和 0.85。与灯光贴图下限分开控制。 |
| `WhiteHot`、`ThermalMode` | 前者使用白色显示场景亮度，后者叠加角色肢体轮廓，两项可分别配置。 |
| `RequiresPower` | 默认关闭。开启后读取同物品 `Powered` 组件的 `HasPower`；装有电池的物品还需要实际供电逻辑。 |

## 渲染与维护

客户端采用 MonoGame 3.7.1 编译的 MGFX v8，两份资源分别嵌入 Windows 客户端（DirectX）及 Linux/macOS 客户端（OpenGL）。着色器源码位于 `CsProjectSource/Shaders/NightVision.fx`。重编时用 2MGFX 对同一源文件分别指定 `/Profile:DirectX_11` 和 `/Profile:OpenGL`。自定义效果加载失败时记录错误并使用原版单色效果；回退模式保留淡变、环境光和普通轮廓。

原版 1.15.33 的 `DrawMap` 在基本拷贝与最终后处理两条路径中都会读取 `renderTargetFinal`。插件拦截这两处读取，开启时把处理后的图像写进原版已用完的全尺寸中间纹理。随后仍由原版完成模糊、畸变、气泡、黑幕和 HUD。

原版会用舱室自己的环境光覆盖舱内灯光贴图，因此提高全局环境光只能照亮舱外，还会削弱玩家身边的光晕。现在客户端在 `RenderLightMap` 画完角色和灯光、即将解绑贴图时，用一次绘制把每个像素的 RGB 分量分别提高到至少 `AmbientBoost × 淡变系数`。原版随后将灯光贴图乘到场景上，再应用视线遮挡。装备的提亮量为零或服务端关闭“允许夜视仪提高环境光”时，跳过这次绘制。

磷光色、增益、黑位、伽马、噪点、扫描线、暗角和镜头畸变均可在物品 XML 调节。`Bloom` 在同一遍绘制中取四个相邻亮部样本。`WhiteHot` 将磷光色改为白色，明暗取自场景亮度。可选热融合依据角色与肢体的原版显示条件绘制，不依赖温度数据。

`ThermalMode` 默认 `Off`。`FusedOutline` 直接绘制肢体轮廓，`Mask` 将轮廓绘入宽高各为四分之一的遮罩，`Edge` 对填充肢体组成的遮罩取边缘。默认每秒刷新六次目标与肢体位置，取视口附近、范围内最近的 16 个角色，上限 32。两次刷新之间，缓存随相机移动。可选测试包包含 `vcenightvisiontest` 护目镜和支持切换信号的 `vcenightvisionlamp` 舱灯。

人类所有未隐藏、未断离的肢体都参与绘制，避免低质量的头部和脚部被漏掉。非人类仍过滤质量低于 0.5 的非主肢体。默认排除佩戴者、死亡角色以及被设为热成像隐藏或不可探测的角色。`ShowDead` 可以开启尸体显示。普通夜视提亮后仍由原版处理视线遮挡；热轮廓有独立的目标筛选，当前实现不会逐目标进行视线射线检测。

维护 Windows 着色器时，保留像素着色器输入的顺序 `SV_Position`、`COLOR0`、`TEXCOORD0`，以匹配原版 SpriteBatch 的顶点输出。此前输入寄存器不匹配会导致绿色或白热画面闪烁。灯光下限绘制的位置同样重要：必须在原版绘完舱室和角色后、解绑灯光贴图前执行，否则舱室自己的底光会覆盖提亮。

## 验证记录

Windows 1.15.33.2 单人实测已获玩家确认。熄灯舱内，绿色夜视能辨认未被光标选中的爬行者和地板；零环境光对照组只在已有微光的范围内较易辨物。后续核对通过的项目包括白热模式、普通夜视下的舱门视线遮挡、热轮廓中的人类头部和双脚，以及供电与切换角色时的画面。

Windows、Linux、macOS 均已编译。Linux/macOS 实际渲染、着色器加载失败时的回退、不同后处理模组组合和各热融合模式的帧耗时仍待验证。单人开服结果未单独记录；远端客户端的佩戴者视角和服务端环境光设置同步需多人复核。
